รวมเอกสารเบิกเงินช่าง

อัปโหลดไฟล์แล้วระบบจะพยายามอ่านเลข PO, S และ INV ให้อัตโนมัติ (แก้ไขเองได้) โดยสาขาตั้งต้นเป็นปากช่องและสามารถแก้ไขได้ เลือกประเภทงานเบิกก่อน แล้วระบบจะนำเอกสารมาต่อกันตามลำดับหัวข้อที่กำหนด โดยรักษาหน้า PDF ต้นฉบับไว้ และแปลงรูปถ่ายเป็นหน้าเอกสาร PDF

เลขเอกสารจะดึงจากข้อความใน PDF หากเป็นไฟล์สแกนหรือรูปถ่าย อาจต้องกรอกเอง

ข้อความสำหรับส่งเบิกเงินช่าง

ระบบจัดข้อความตามประเภทงานและข้อมูลที่กรอก สามารถแก้ไขข้อความก่อนคัดลอกได้

อัปโหลดเอกสารตามลำดับ

กรุณาอัปโหลดเอกสารบัญชีช่างจากเครื่องของแอดมิน • เพิ่มหลายไฟล์ในช่องเดียวกันได้ และใช้ปุ่ม ↑ ↓ เพื่อจัดลำดับไฟล์ภายในช่องก่อนรวม

สร้างไฟล์ PDF รวม

ยังไม่ได้เลือกเอกสาร

ข้อควรระวัง: GitHub Pages เป็นเว็บไซต์สาธารณะ ไม่ควรฝังข้อมูลบัญชีธนาคารหรือบัตรประชาชนลงในโค้ด • ข้อมูลและไฟล์จะถูกประมวลผลภายในเบราว์เซอร์ ไม่ได้ส่งเอกสารไปยังเซิร์ฟเวอร์ของระบบนี้ • ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดชุดคำสั่งจัดการ PDF ครั้งแรก • รองรับ PDF, JPG, JPEG และ PNG • ไฟล์ PDF ที่ใส่รหัสผ่านอาจไม่สามารถรวมได้
